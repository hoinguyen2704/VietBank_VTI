## 📊 BẢNG LỘ TRÌNH THỰC TẬP

| Tuần  | Nội dung thực tập                                                                                                                                                                                                                                                                                                                                                                                              | Kết quả đạt được                                                                                                                                                                                                                                                                                                                                                                                                    | Ghi chú                                                                                                                                                                                                                                                                     |
| :---: | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1** | **Tìm hiểu doanh nghiệp & Thiết kế Database**<br><br>- Tìm hiểu lịch sử hình thành, cơ cấu tổ chức, quy định và văn hóa làm việc tại VTI<br>- Làm quen với team, mentor và quy trình làm việc (Agile/Scrum)<br>- Cài đặt môi trường phát triển trên Linux (Ubuntu Server)<br>- Ôn tập và thực hành thiết kế, tối ưu hóa CSDL với MySQL<br>- Phân tích yêu cầu dự án<br>- Thiết kế sơ đồ ERD và viết script SQL | - Hiểu rõ văn hóa doanh nghiệp, cách thức tổ chức và vận hành công ty IT<br><br>- Nắm vững quy trình Agile/Scrum: Daily standup, Sprint planning, Retrospective<br><br>- Thành thạo cài đặt và cấu hình môi trường dev trên Linux<br><br>- Củng cố kiến thức MySQL: Normalization, Index, Foreign Key, Constraints<br><br>- Hoàn thành ERD với 6 bảng chính và script SQL                                           | - Hội nhập văn hóa<br>- Tham khảo các ứng dụng ngân hàng thực tế: Vietcombank, BIDV, TPBank, Techcombank<br>- Sử dụng Ubuntu Server làm môi trường phát triển<br>- Chú ý quy ước đặt tên bảng và cột theo chuẩn snake_case<br>- Áp dụng soft delete cho các bảng quan trọng |
| **2** | **Xây dựng Project Base Spring Boot**<br><br>- Tạo project Spring Boot với các dependencies cần thiết<br>- Cấu hình kết nối database, JPA/Hibernate<br>- Thiết lập cấu hình đa ngôn ngữ (i18n)<br>- Tạo cấu trúc package chuẩn<br>- Tạo các class cơ sở: BaseEntity, BaseResponse, GlobalExceptionHandler<br>- Cấu hình Swagger/OpenAPI                                                                        | - Hiểu rõ kiến trúc layered architecture: Controller → Service → Repository<br><br>- Nắm vững cách cấu hình Spring Boot với application.yml<br><br>- Biết cách tổ chức package theo chuẩn enterprise<br><br>- Hiểu và áp dụng được Lombok để giảm boilerplate code<br><br>- Cấu hình thành công Swagger để tự động tạo API documentation                                                                            | - Sử dụng Maven làm build tool<br>- Áp dụng Lombok để giảm boilerplate code<br>- Cấu hình Hibernate ddl-auto=validate để không tự động thay đổi schema                                                                                                                      |
| **3** | **Phát triển API Quản lý Khách hàng (STAFF)**<br><br>- Tạo Customer entity và repository<br>- Implement tìm kiếm với JPA Specification<br>- Xây dựng các API CRUD cho Customer<br>- Áp dụng Bean Validation và custom validator<br>- Implement soft delete<br>- Test APIs với Postman                                                                                                                          | - Thành thạo mapping Entity với database bằng JPA annotations<br><br>- Hiểu và áp dụng được JPA Specification cho dynamic query<br><br>- Nắm vững RESTful API design: HTTP methods, status codes, request/response format<br><br>- Biết cách validate input với Bean Validation và tạo custom validator<br><br>- Hiểu concept soft delete và áp dụng trong thực tế                                                  | - Sử dụng Page cho phân trang<br>- Soft delete bằng cách set deletedAt = current timestamp<br>- Custom exception: CustomerNotFoundException, DuplicatePhoneNumberException, DuplicateCitizenIdException                                                                     |
| **4** | **Phát triển API Quản lý Tài khoản (STAFF)**<br><br>- Tạo Account entity với quan hệ ManyToOne đến Customer<br>- Implement auto-generate account number<br>- Xây dựng các API CRUD cho Account<br>- Tạo Transaction entity để ghi log giao dịch<br>- Implement tính năng nạp tiền (Deposit)                                                                                                                    | - Hiểu và áp dụng được các loại relationship trong JPA: OneToMany, ManyToOne<br><br>- Biết cách tự động generate unique identifier (account number)<br><br>- Hiểu tầm quan trọng của @Transactional trong xử lý giao dịch tài chính<br><br>- Nắm vững cách thiết kế transaction log cho audit trail<br><br>- Xử lý được số tiền với BigDecimal để tránh lỗi floating point                                          | - Sử dụng @Transactional cho deposit operation đảm bảo tính toàn vẹn dữ liệu<br>- Currency mặc định là VND<br>- Mỗi Customer có thể có nhiều Account<br>- Balance kiểu BigDecimal để tránh lỗi floating point                                                               |
| **5** | **Phát triển API cho Khách hàng & Chuyển khoản (CUSTOMER)**<br><br>- Xây dựng APIs xem/cập nhật thông tin cá nhân<br>- Xây dựng APIs xem tài khoản và số dư<br>- Implement tính năng chuyển khoản với validation đầy đủ<br>- Xây dựng API xem lịch sử giao dịch<br>- Xử lý các exception đặc thù                                                                                                               | - Hiểu cách thiết kế API theo role-based access (phân biệt STAFF vs CUSTOMER)<br><br>- Nắm vững business logic phức tạp: validate số dư, kiểm tra tài khoản đích, giới hạn chuyển khoản<br><br>- Biết cách xử lý concurrent transactions và đảm bảo data consistency<br><br>- Thành thạo custom exception handling với meaningful error messages<br><br>- Hiểu cách thiết kế API cho end-user với UX tốt            | - Sử dụng @Transactional với isolation level SERIALIZABLE cho transfer<br>- Rollback tự động khi transfer thất bại                                                                                                                                                          |
| **6** | **Authentication, Phân quyền & Triển khai**<br><br>- Implement JWT Authentication (login, logout, refresh token)<br>- Cấu hình Spring Security và phân quyền theo role<br>- Testing toàn bộ APIs<br>- Triển khai dự án lên server Linux<br>- Cấu hình Nginx và SSL/HTTPS<br>- Viết báo cáo và demo dự án                                                                                                       | - Hiểu rõ cơ chế JWT: Access token, Refresh token, Token expiration<br><br>- Nắm vững Spring Security: Authentication, Authorization, SecurityFilterChain<br><br>- Biết cách phân quyền API theo role với @PreAuthorize<br><br>- Thành thạo deploy ứng dụng Spring Boot lên Linux server<br><br>- Hiểu cách cấu hình Nginx reverse proxy và SSL certificate<br><br>- Hoàn thành báo cáo thực tập và demo thành công | - Access token expiration: 5 phút<br>- Refresh token expiration: 1 ngày<br>- Đăng nhập bằng số điện thoại + mật khẩu<br>- Mật khẩu được hash với BCrypt<br>- Lưu token blacklist khi logout<br>- Sử dụng Nginx + SSL cho production                                         |
